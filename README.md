E-book para iniciantes em jardinagem

## 📒 Descrição
Criar através de IA um e-book que possa auxiliar pessoas que desejam iniciar no mundo do jardinagem

## 🤖 Tecnologias Utilizadas
Foi utilizado o bing chat

## 🧐 Processo de Criação
Solicitei ao bing chat a criação do e-book e a partir do resultado fui solicitando que especificasse mais em alguns tópicos até chegar ao resultado final.
